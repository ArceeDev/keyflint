Pattern 1: Wrapping Any Existing MCP Server in 30 Seconds

If you already have an MCP server in any language and want to gate tools without rewriting its source code, wrap it with @keyflint/wrap:

npx @keyflint/wrap \
  --tool parse_statement=2 --tool export_journal=5 \
  -- npx -y @your-org/your-mcp-server

The license, your public keys and the gateway URL come from KEYFLINT_LICENSE, KEYFLINT_PUBLIC_KEYS and KEYFLINT_URL.

When a user runs out of credits, the wrapper intercepts the call before your server executes and returns JSON-RPC error -32062 pointing to your top-up link (KEYFLINT_CHECKOUT_URL), which can add credits to the same license key.

Pattern 2: Decorator-Based Metering in Python & TypeScript

For fine-grained control inside FastMCP or the official MCP SDK, use keyflint-verify:

from keyflint_verify.mcp import KeyFlint

kf = KeyFlint()

@mcp.tool()
@kf.metered(credits=4)
def audit_invoice_xml(xml_payload: str) -> dict:
    # Automatically refunded if an exception is raised or isError=True is returned
    return audit(xml_payload)  # your own tool logic

Pattern 3: Dual-Surface Monetization (MCP + Browser Batch UI)

Many B2B buyers discover your tool through Google Search before they ever install an MCP client. By exposing the same KeyFlint-metered container tools behind a browser drag-and-drop UI (like mcp.keyflint.dev/lote), the exact same LIC-... token and credit balance work across Claude Desktop, Cursor, REST APIs, and the web browser.
