Gateway autoalojado · Ed25519 (RFC 8032) · SQLite WAL

Licencias firmadas y cuotas de créditos para servidores MCP, CLIs y APIs.

Emites tokens Ed25519 que el cliente verifica sin red. Cada llamada descuenta créditos de forma atómica e idempotente, y se reembolsa si la herramienta falla. Stripe y LemonSqueezy emiten y revocan licencias por webhook firmado.

Cómo funciona

De la compra a la llamada cobrada, en 4 pasos

  1. 1

    Despliega el gateway

    Un contenedor Docker con un volumen SQLite. Sin Postgres ni Redis.

  2. 2

    Conecta tus pagos

    Cada compra en Stripe o LemonSqueezy emite la licencia por webhook firmado y la envía por correo.

  3. 3

    Verifica sin red

    Tu app comprueba el token Ed25519 en local con keyflint-verify, en menos de 1 ms.

  4. 4

    Cobra por uso

    Cada llamada descuenta créditos con @metered. Si la tool falla, se reembolsan solos.

Integración

keyflint-verify en PyPI y npm, go-verify para Go. Licencia MIT.

from keyflint_verify.mcp import KeyFlint

kf = KeyFlint()  # lee KEYFLINT_LICENSE, KEYFLINT_PUBLIC_KEYS y KEYFLINT_URL

# 2 créditos por llamada; reembolso automático si la tool lanza o devuelve isError
@mcp.tool()
@kf.metered(credits=2)
async def analizar_codigo(repo_url: str) -> str:
    return await run_ai_audit(repo_url)

Preguntas frecuentes

            


            

                

                    
                    

                        Sí, con tokens Ed25519. El cliente embebe la clave pública (o el keyring de /api/v1/licenses/public-key) y verifica firma, caducidad, nodo y dominio en local. Los tokens HMAC-SHA256 solo se validan online, porque el secreto no puede salir del servidor.
                    

                


                

                    
                    

                        Define ED25519_KID para la clave nueva y mueve la anterior a ED25519_RETIRED_PUBLIC_KEYS. Los SDKs eligen la clave por kid; los tokens sin kid (v1.0) siguen siendo válidos.
                    

                


                

                    
                    

                        Un contenedor Docker con un volumen persistente para el archivo SQLite. No requiere Postgres, Redis ni colas externas.
                    

                


                

                    
                    

                        Decora la tool con @metered(credits=N). El descuento es atómico en SQLite WAL. Sin saldo, la tool devuelve el error JSON-RPC -32062 sin ejecutarse.
                    

                


                

                    
                    

                        Si lanza una excepción o devuelve isError, el SDK llama a POST /api/v1/quota/refund con la misma clave de idempotencia. El reembolso es idempotente y solo se acepta dentro de QUOTA_REFUND_WINDOW_SECONDS (900 s por defecto).
