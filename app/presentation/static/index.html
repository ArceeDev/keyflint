Preguntas Frecuentes

                
Todo lo que necesitas saber antes de desplegar o integrar KeyForge.

            


            

                

                    

                        ¿Pueden mis usuarios validar su licencia en un avión o sin conexión a internet?
                        +
                    

                    

                        Sí, al 100%. Gracias a la criptografía asimétrica Ed25519 (RFC 8032), tus clientes reciben la clave pública y comprueban la firma matemática del token de forma local en menos de 0.1 milisegundos, sin enviar ninguna petición por internet.
                    

                


                

                    

                        ¿Qué infraestructura necesito para alojar el servidor de KeyForge?
                        +
                    

                    

                        Cualquier servidor básico con Docker (un VPS de $4 a $5 USD/mes en Hetzner o DigitalOcean, o incluso planes Always Free de Oracle Cloud). El backend consume menos de 60 MB de memoria RAM y no requiere bases de datos pesadas externas.
                    

                


                

                    

                        ¿Cómo funciona el cobro de créditos en servidores MCP de Inteligencia Artificial?
                        +
                    

                    

                        Solo tienes que añadir el decorador `@metered(credits=2)` sobre tus herramientas de MCP en Python o TypeScript. KeyForge descuenta los créditos de forma atómica con SQLite WAL. Si el cliente agota sus fichas, responde con el error estándar JSON-RPC -32042 y el enlace directo de recarga.
                    

                


                

                    

                        ¿Qué ocurre si la herramienta falla durante su ejecución?
                        +
                    

                    

                        La versión 1.1 incluye reembolso automático: si la función del servidor MCP lanza una excepción o devuelve un error, el SDK se comunica con el endpoint seguro `/api/v1/quota/refund` usando la clave de idempotencia original y restituye los créditos al cliente de inmediato.
                    

                


                

                    

                        ¿Cómo recibo el dinero de las ventas?
                        +
                    

                    

                        KeyForge se conecta directamente con tu cuenta de Stripe o LemonSqueezy. Los clientes pagan con tarjeta de crédito, Apple Pay o Google Pay, y el dinero va directo a tu cuenta bancaria sin comisiones abusivas de plataformas intermediarias.
